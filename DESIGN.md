# Design (Dark Mode)

Tailwind-Standardfarben, eine Akzentfarbe (violet). Diese Klassen bitte in allen Seiten und Karten verwenden.

| Zweck | Klassen |
| --- | --- |
| Seitenhintergrund | `bg-zinc-950 text-zinc-100` |
| Fläche / Karte | `bg-zinc-900 border border-zinc-800 rounded-2xl` |
| Karte Hover | `transition hover:-translate-y-1 hover:border-zinc-700` |
| Titel | `font-semibold text-zinc-100` |
| Nebeninfo (Jahr, Bewertung, Beschreibung) | `text-sm text-zinc-400` |
| Primärer Button | `rounded-lg bg-violet-600 px-3 py-2 text-sm font-semibold text-white transition hover:bg-violet-500` |
| Button deaktiviert ("Gespeichert ✓") | `disabled:bg-zinc-800 disabled:text-zinc-400 disabled:cursor-default` |
| Akzent-Text / Links | `text-violet-400 hover:text-violet-300` |
| Poster-Platzhalter | `bg-zinc-800 text-zinc-500` |
