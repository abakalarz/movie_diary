# Movie Diary

Gruppenprojekt: Web-App mit der TMDB-API (HTML, JavaScript, Tailwind CSS).

## Team-Regeln

- Keine direkten Pushes auf main, alles läuft über Pull Requests.
- Jeder PR braucht mindestens 1 Approval eines anderen Teammitglieds.
- Branch-Namen: feature/<kurzname>, zum Beispiel feature/search-dialog
- Commit-Nachrichten mit Präfix: feat, fix, chore oder docs, zum Beispiel "feat: add movie card"

## Starten

1. js/config.example.js nach js/config.js kopieren
2. TMDB-Token eintragen
3. Seite mit Live Server öffnen (Rechtsklick auf index.html → "Open with Live Server")
